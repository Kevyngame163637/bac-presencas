Este projeto usa Vite e Supabase. 2. Envie TODOS os arquivos e pastas deste ZIP para a raiz do repositório bac-presencas no GitHub. 3. Na Vercel, abra Settings > Environment Variables. 4. Crie/renomeie as variáveis para estes nomes EXATOS: VITE_SUPABASE_URL = Project URL do Supabase VITE_SUPABASE_ANON_KEY = Publishable key (sb_publishable_...) Marque Production, Preview e Development. As variáveis antigas SUPABASE_URL e SUPABASE_ANON_KEY não são lidas pelo Vite; remova-as depois de confirmar as novas. 5. Em Vercel > Deployments, faça Redeploy ou aguarde o deploy automático. Build command: npm run build Output directory: dist Install command: npm install 6. No Supabase, o SQL do banco deve ter sido executado antes de usar o painel.
